全自动上传到 Telegram（推荐，无需逐个发送）

选择要上传的包（超过 120 张会自动拆成多个包）：勾选即上传，取消则不创建该包。想要复用之前生成过的包？点下方「从历史包选择上传」。
准备：1) 找 @BotFather 建 bot 拿 token；2) 找 @userinfobot 得到你的数字 ID；3) 先给自己 bot 发一条 /start（必做）。 token 与用户 ID 已从环境变量（start.bat）读取，无需填写。

备选：手动上传（发给 @Stickers）

1. 在 Telegram 搜索并打开 @Stickers 机器人，发送 /newpack（静态）或 /newanimated（动图）。
2. 按提示发送贴纸包的显示名称（随意），再发送 short_name（必须以 _by_你的机器人名 结尾——没有 bot 的话先找 @BotFather 免费建一个，只是为了注册包名）。
3. 解压下载的 zip：static/ 里的文件发给静态包，animated/ 里的发给动图包（注意：一个包只能全静态或全动图）。
4. 逐个文件以【文件 File】方式发送（不要发成图片，否则会被压缩），全部发完后发送 /publish，再发送 short_name 确认即可。
5. 也可以先发 /addsticker 向已有贴纸包追加。
